# Creating the Technical Video Parent Issue on GitHub

This document provides instructions for creating the Technical Video parent issue on GitHub.

## Quick Steps

1. Go to: https://github.com/J-S-webskas/Technovation/issues/new
2. Copy the content from `TECHNICAL_VIDEO_ISSUE.md` into the issue description
3. Set the following metadata:
   - **Title:** `Create Technical Video for YouTube according to judging rubric`
   - **Labels:** Add `documentation` label
   - **Milestone:** Set to `Technical Video Uploaded`
   - **Project:** Add to `Board` project
4. Click "Submit new issue"

## Issue Title (copy this exactly)

```
Create Technical Video for YouTube according to judging rubric
```

## Issue Description (copy from TECHNICAL_VIDEO_ISSUE.md)

The complete issue description is in the `TECHNICAL_VIDEO_ISSUE.md` file in the repository root.

## Metadata Configuration

### Label
- `documentation` (should already exist in the repository)

### Milestone
- `Technical Video Uploaded` (create if it doesn't exist)

### Project
- `Board` (should already exist in the repository)

## Creating Sub-Issues

After creating the parent issue, consider creating individual sub-issues for each major task:

1. Script Development for Technical Video
2. Content Preparation for Technical Video
3. Video Recording for Technical Video
4. Video Editing for Technical Video
5. Review & Finalization of Technical Video
6. YouTube Upload of Technical Video

Each sub-issue should reference the parent issue number (e.g., "Part of #XX" where XX is the parent issue number).

## Alternative: Using GitHub CLI

If you have GitHub CLI (`gh`) installed and authenticated, you can create the issue with:

```bash
gh issue create \
  --title "Create Technical Video for YouTube according to judging rubric" \
  --body-file TECHNICAL_VIDEO_ISSUE.md \
  --label documentation \
  --milestone "Technical Video Uploaded" \
  --project "Board"
```

Note: You may need to adjust the milestone and project names based on their exact names in your repository.
