# Technovation Competition Documentation

This repository contains the codebase for the Technovation competition project - a mobile application for monitoring gait and motion to detect symptoms early in patients with neurological conditions.

This project requires several deliverables for the Technovation competition:

### 3. Pitch Video (Issue #37, #44)

## Project Structure

This is an Android application built with Java and Gradle. Key components include:

- **MainActivity.java** - Main entry point
- **Session Management** - Track and display user sessions (sessionsMain.java, sessionData.java, demoSession.java)
- **Layout Files** - XML layouts for various activities
- **Computer Vision** - Integration with MediaPipe for motion tracking

## Technical Video Requirements Summary

The Technical Video must cover:

1. **App Demonstration** - Working parts of the app
2. **End Users & Testing** - Who uses it and how it was tested
3. **AI Usage Path** - Either:
   - GenAI-assisted development (tools and prompts), OR
   - Traditional coding/ML training for key features
4. **Iterative Development** - Development process and user feedback integration

**Full details in `TECHNICAL_VIDEO_ISSUE.md`**
