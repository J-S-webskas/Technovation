# Create Technical Video for YouTube according to judging rubric

## Issue Metadata
- **Label:** documentation
- **Milestone:** Technical Video Uploaded
- **Project:** Board
- **Type:** Parent Issue

## Description

Create and upload a Technical Video to YouTube addressing the following criteria from the judging rubric:

### 1. App Demonstration
- Give a demonstration of the working parts of the app you have built
- Show key features and functionality in action
- Highlight the user interface and user experience
- Demonstrate the technical capabilities of the application

### 2. End Users & Testing
- Explain who the end users are (e.g., patients with neurological conditions, healthcare providers)
- Show how the app was tested with actual end users
- Document user feedback and testing results
- Include any user testimonials or case studies if available

### 3. AI Usage Path (choose one based on your answer to "Did you use AI?")

#### If YES - Technical Development (GenAI-assisted apps):
- Explain the generative AI process used in either coding or building an AI model for the project
- Include specific tools used (e.g., GitHub Copilot, ChatGPT, Claude, etc.)
- Provide example prompts that were used during development
- Demonstrate how AI assistance improved the development process

#### If NO - Coding (traditional apps):
- Explain what machine learning training and/or actual coding you did for 1-2 important parts of your app
- **Note:** Do NOT focus on login screen - choose substantive features
- Show technical implementation details
- Explain the algorithms or approaches used
- Demonstrate the technical complexity and problem-solving involved

### 4. Iterative Development
- Describe the team's iterative development process
- Show how user feedback was incorporated into the development cycle
- Explain testing methodologies and iterations
- If applicable: Describe how AI prompt modification improved results over time
- Document the evolution of the project from initial concept to current state

## Deliverable

The final video should be:
- Uploaded to YouTube
- Professionally produced and edited
- Clear and engaging for judges
- Ready for competition submission
- Compliant with all competition requirements and time limits

## Sub-tasks

This parent issue should be broken down into the following sub-tasks:

1. **Script Development**
   - Write comprehensive script covering all four sections
   - Review and refine script with team
   - Time the script to ensure it fits within competition limits

2. **Content Preparation**
   - Prepare app demonstration materials
   - Gather user testing documentation and testimonials
   - Compile AI usage examples and prompts (if applicable)
   - Document iterative development timeline and changes

3. **Video Recording**
   - Record screen captures of app demonstration
   - Film team member explanations
   - Capture any user testing footage (with permissions)

4. **Video Editing**
   - Edit footage into cohesive narrative
   - Add transitions, titles, and graphics
   - Ensure audio quality
   - Include captions if required

5. **Review & Finalization**
   - Team review of draft video
   - Incorporate feedback
   - Final quality check

6. **YouTube Upload**
   - Create/optimize YouTube video listing
   - Upload final video
   - Set appropriate privacy settings
   - Add description and tags
   - Verify upload meets competition requirements

## Success Criteria

- [ ] Video covers all four required sections from judging rubric
- [ ] Video demonstrates working app features
- [ ] End users and testing are clearly explained
- [ ] AI usage or coding process is thoroughly documented
- [ ] Iterative development process is described
- [ ] Video is uploaded to YouTube
- [ ] Video meets competition time and format requirements
- [ ] Video is professional and engaging

## Notes

- Ensure all footage respects user privacy and has appropriate permissions
- Follow competition guidelines for video length and format
- Make the video engaging and clear for judges who may not be technical experts
- Highlight the unique aspects and innovations of the project
